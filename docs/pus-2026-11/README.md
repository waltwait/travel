# PUS 2026 釜山行程

2026/11/27–11/30 釜山四天三夜的 one-page 行程網站。

- `index.html`：網頁本體（版面、樣式、渲染程式）
- `itinerary.js`：行程資料，**改行程只要改這個檔案**（欄位說明寫在檔案開頭）

## 功能

- 航班資訊（去程 JX900、回程 JX901，星宇航空）；住宿 Kwangsu Hotel（海雲台）
- 每天一條時間軸：停留點是編號站牌，移動是虛線
- 藍字 = 正餐，紅字 = 已預約，藍底「釜山 Pass」= Visit Busan Pass 免費的景點（`itinerary.js` 地點加 `pass: true`）
- 地圖都開 Naver Map（韓國的 Google 地圖不能導航）：點地名是 Naver Map 搜尋
- 每個地點都有「導航」按鈕：手機上直接開 Naver Map App，有座標（`at`）就從目前位置規劃大眾運輸路線，沒有就先搜尋；旅途中頂部會顯示「下一站」
- 沒有新加坡那頁的「整天路線」，因為 Naver Map 不能用網址開多點的大眾運輸路線
- 出發前顯示倒數天數；旅途中會依韓國時間標出「進行中」的行程
- 支援手機、深色模式

手機要先裝 Naver Map App（iPhone、Android 都有），「導航」才打得開。

## 時差

韓國（UTC+9）比台灣快 1 小時。跟新加坡那頁不一樣的地方：

- 航班多了 `utc`（台灣 8、韓國 9），飛行時間會扣掉時差
- 搭飛機那一列加 `flight: "JX900"`。同一天起飛前、落地回台灣後的列照台灣時間寫，網頁會換算成韓國時間來判斷「進行中」「下一站」，並在第一列標「台灣時間」；這些列不會串進當地的 Google 地圖路線
