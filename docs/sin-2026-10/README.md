# SIN 2026 新加坡行程

2026/10/17–10/19 新加坡三天兩夜的 one-page 行程網站。

- `index.html`：網頁本體（版面、樣式、渲染程式）
- `itinerary.js`：行程資料，**改行程只要改這個檔案**（欄位說明寫在檔案開頭）

## 功能

- 航班資訊（去程 TR873、回程 JX772）
- 每天一條時間軸：停留點是編號站牌，移動是虛線
- 藍字 = 正餐，紅字 = 已預約（沿用 Notion 的標色）
- 點地名直接開 Google 地圖
- 每個地點都有「導航」按鈕（Google 地圖，從目前位置出發）；旅途中頂部會顯示「下一站」
- 每天依早上、下午、晚上分成幾條 Google 地圖路線，依時間順序串起所有地點
- 出發前顯示倒數天數；旅途中會依新加坡時間標出「進行中」的行程
- 支援手機、深色模式

## 本機預覽

直接用瀏覽器打開 `index.html` 即可。
