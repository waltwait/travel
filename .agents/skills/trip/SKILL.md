# 旅行進度總管 (trip)

本技能是整套旅行規劃技能的萬用入口。無論使用者身在規劃的哪一個階段，或是想在多個行程間切換，皆由此統一偵測進度並引導下一步。

---

## 執行流程

### 步驟 1：解析當前行程資料夾（永遠先做）

1. **掃描行程資料夾**：
   列出目錄下符合 `{編號}-{地點}-{YYYY-MM-DD}` 格式的行程資料夾（例如 `1-布達佩斯-2026-04-24/`、`2-釜山-2026-10-18/`）。
2. **讀取指標檔 `./current-trip`**：
   嘗試讀取根目錄的純文字指標檔 `./current-trip`（記錄當前行程資料夾名稱）。

#### 分支判斷：

* **分支 1a：指標檔存在且有效**（指向實際存在的行程資料夾）：
  * 直接以該資料夾為當前行程 `$TRIP`，進入步驟 2。
* **分支 1b：指標檔不存在 / 內容空白 / 指向無效資料夾，但有現有行程資料夾**：
  * 向使用者列出所有現有行程（格式：「**地點** — 開始研究 YYYY-MM-DD」），並附帶「🆕 開始規劃新行程」選項。
  * 若使用者選擇既有行程：將該資料夾名稱寫入 `./current-trip`，進入步驟 2。
  * 若選擇新行程：直接引導至 `trip-plan` 技能。
* **分支 1c：完全沒有任何行程資料夾（全新工作區）**：
  * 靜默檢查是否有舊版殘留檔案（如根目錄遺留的 `research/`、`final-itinerary.md`）。若有，詢問是否整理遷移至新資料夾；若無，直接引導使用者開始規劃第一個行程（呼叫 `trip-plan`）。

---

### 步驟 2：讀取當前行程進度

令 `$TRIP` 為當前解析出的行程資料夾名稱。依序檢查下列檔案之**實質內容**（非單純檢查檔案存在）：

| 檢查項 | 檔案位置 | 說明 |
| :--- | :--- | :--- |
| **A. 規劃檔** | `./$TRIP/trip-meta.md` | 是否已建立基本資料（目的地、日期、預算、旅伴等） |
| **B. 旅行者畫像** | `./traveler-profile.md` | 根目錄共用畫像（人的屬性：飲食、體力、偏好） |
| **C. 研究報告** | `./$TRIP/research/` | 是否含有實質研究報告（非空骨架或待補清單） |
| **D. 每日排程** | `./$TRIP/final-itinerary.md` 或 `overview.md` 或網站 `itinerary.js` | 是否已排出每日動線與時間表 |
| **E. 審查報告** | `./$TRIP/review.md` | 是否已完成可行性、交通與時差審查 |
| **F. 行前清單** | `./$TRIP/checklist.md` | 是否已產出分階段行前待辦與打包清單 |

---

### 步驟 3：判定狀態與下一步指引

從上至下比對，首個符合的條件即為目前狀態：

| 條件 | 當前狀態 | 說明與下一步指引 | 對應技能 |
| :--- | :--- | :--- | :--- |
| A 存在且狀態為 `aborted` | **已放棄** | 先前已標記放棄。可改回 `active` 續用，或建立新行程。 | `trip-plan` |
| A 不存在 | **尚未規劃** | 尚未完成行程基本資料收集。 | `trip-plan` |
| A 存在、B 不存在 | **畫像未填** | 基本資料已建，尚欠旅行者個人畫像。 | `trip-plan` |
| A、B 存在，C 缺乏實質內容 | **已規劃，未研究** | 需要針對景點、美食、交通、住宿與簽證進行深度研究。 | `trip-research` |
| C 完成，D 缺乏每日安排 | **已研究，未排程** | 研究完成，需要串連每日景點動線、門到門交通與預算。 | `trip-go` |
| D 完成，E 不存在或有嚴重未決項 | **已排程，未審查** | 排程完成，需要自動檢查休館日、時差、轉機 MCT 與銜接可行性。 | `trip-review` |
| E 審查通過，F 未產出 | **已審查，未備清單**| 建議出發前 1-2 週生成分階段行前待辦、打包清單與緊急卡。 | `trip-pack` |
| 全部完成 | **規劃全部完成** | 行程完整就緒。可隨時轉為手機網頁版，或在旅途中進行記帳與動態替代推薦。 | `travel-planner` |

---

### 步驟 4：格式化輸出與引導

1. **標題行（鎖定行程時一律以此行開頭）**：
   ```
   📍 目前在規劃 **{$TRIP 資料夾名}**
   ```
2. **行程概要摘要**：
   ```
   {目的地} · {日期範圍} · {天數} · {旅伴}
   ```
3. **可視化進度條**：
   ```
   進度：✅ 規劃 · ✅ 研究 · ⏳ 排程 · ⬜ 審查 · ⬜ 行前準備
   ```
   * `✅` 已完成
   * `⏳` 當前/下一步要做的
   * `⬜` 尚未開始
4. **下一步指引與確認**：
   用簡明文字詢問使用者是否接續執行下一步，或提供具體切換/新增行程提示。
   * 若目錄下有 ≥ 2 個行程，文末附加：
     > 💡 想切換至其他行程或建立新行程？隨時輸入「切換行程」或「新增行程」。

---

### 步驟 5：使用者確認後

當使用者確認進行下一步或說「好」「繼續」「下一步」時，直接進入對應技能（`trip-plan`、`trip-research`、`trip-go`、`trip-review`、`trip-pack`、`travel-planner`），無須反覆確認。
