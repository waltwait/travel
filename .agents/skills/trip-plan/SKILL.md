# 旅行初始化與設定 (trip-plan)

本技能協助使用者從零開始規劃一趟旅程，或修改現有行程的基本設定。

---

## 核心工作原則

1. **區分共用與專屬**：
   * **根目錄 `traveler-profile.md`**：存跨行程共用的「人的屬性」（飲食忌口、體力、語言能力、常態旅行經驗等）。
   * **行程資料夾 `./$TRIP/trip-meta.md`**：存該趟專屬設定（目的地、日期、同行旅伴、本趟預算、本趟住宿等級、排除項目等）。
2. **安全防護與局部修改**：
   * 修改現有行程時，必須**局部更新**，絕對不得用空白範本覆蓋既有的已訂航班、飯店、Pass、自訂筆記或未知欄位。
   * 放棄行程時，將狀態標記為 `aborted`，**切勿使用 `rm -rf` 刪除資料夾**。
3. **智慧「幫我決定」**：
   * 所有選項均允許使用者選擇「幫我決定」。
   * 需根據已有訊號（旅伴、預算、體力）進行合理推論，並在最後摘要時向使用者透明說明推論理由（「依據你的 X，我替你選擇了 Y」）。

---

## 執行流程

### 步驟 0：解析目前狀態與路徑

1. 檢查目錄下所有行程資料夾（格式：`{編號}-{地點}-{YYYY-MM-DD}`）。
2. 讀取 `./current-trip`：
   * **分支 0a：全新工作區（無任何行程）**：進入「步驟 1：建立新行程」。
   * **分支 0b：有既有行程且指向有效**：詢問使用者是要「修改此行程設定」、「切換至其他行程」、還是「🆕 建立全新行程」。
   * **分支 0c：指標無效但有候選行程**：列出清單供選擇，或建立新行程。

---

### 步驟 1：建立新行程與資料夾命名

若為建立新行程：
1. **目的地確認**：
   * 詢問使用者想去哪裡（城市、國家或區域皆可）。
   * 若使用者沒有想法或請求推薦，啟動「目的地反推」：先詢問核心興趣與預算天數，檢索並推薦 3 個候選目的地（其中至少 1 個為知名熱門城市作為心理錨點，並附帶預算估算）。
2. **計算編號與日期**：
   * 編號：現有最大編號 + 1（若無則為 1）。
   * 日期：以今天系統日期 `YYYY-MM-DD` 為準（代表開始研究的日期，非旅行出發日期）。
   * 組合資料夾名：`{編號}-{地點}-{YYYY-MM-DD}`（例如 `1-布達佩斯-2026-04-24`）。
3. **建立資料夾與指標**：
   * 建立資料夾 `./{資料夾名}/`。
   * 將資料夾名寫入根目錄 `./current-trip`。
   * 在回應開頭標註：`📍 目前在規劃 **{資料夾名}**`。

---

### 步驟 2：收集本次旅行基本條件

收集以下關鍵要素（已知的直接沿用，缺少的向使用者詢問）：
1. **預計出發日期與天數**（若機票已訂，可直接提供航班時間與班次）。
2. **本次預算範圍**（不含機票，以日常花費與住宿為主）。
3. **同行夥伴**（獨旅、情侶/夫妻、家庭帶小孩、長輩同行、朋友團體）。

---

### 步驟 3：檢查或建立旅行者畫像（`traveler-profile.md`）

讀取根目錄 `./traveler-profile.md`：
* **若檔案已存在**：展示摘要，詢問是否「沿用（推薦）」或「僅修改部分欄位」。
* **若不存在或需全新建立**：收集以下個人屬性（允許「幫我決定」）：
  * **飲食習慣**：什麼都吃 / 素食 / 清真 / 過敏與特殊忌口。
  * **體能狀況**：暴走型（每日步數高）/ 適中 / 需要適度休息 / 行動不便。
  * **語言能力**：當地語言流利 / 英語基本溝通 / 需仰賴翻譯工具。
  * **旅行經驗**：老手（習慣完全自由行）/ 去過幾次 / 首次出國自助。

#### 「幫我決定」推論邏輯範例：
* 預算等級：家庭帶小孩預設「該省省該花花」；蜜月/情侶紀念偏向「高品質」。
* 體能狀況：家庭帶幼童或長輩預設「需要常休息」；戶外冒險愛好者預設「暴走型」。
* 住宿類型：家庭有兒童偏向推薦具廚房與洗衣設備的包棟/公寓式住宿。

---

### 步驟 4：建立專案子結構與 `trip-meta.md`

在 `./$TRIP/` 底下建立以下子目錄：
* `research/`：研究報告存放處
* `flights/`：機票與航班資訊
* `lodging/`：住宿訂單與地址
* `insurance/`：保險與醫療須知

#### 寫入/更新 `./$TRIP/trip-meta.md`：

```markdown
# {目的地} 旅行規劃

> 行程資料夾：{$TRIP}
> 開始研究日期：{YYYY-MM-DD}

## 狀態
active

## 行程概要
- 目的地：{目的地}
- 日期：{日期範圍或預估月份}
- 天數：{N} 天
- 人數與旅伴：{旅伴描述}
- 預算範圍：{金額與幣別}

## 本趟行程設定
- 預算等級：{能省則省 / 該省省該花花 / 高品質}
- 核心興趣：{美食 / 歷史文化 / 攝影 / 戶外 / 購物 / 放鬆}
- 住宿偏好：{商務旅館 / 精品飯店 / 民宿公寓}
- 排除項目：{不想去的景點類型或限制}

## 關鍵檔案
- 旅行者畫像：`../traveler-profile.md`
- 研究報告：`./research/`
- 最終行程：`./final-itinerary.md`
- 記帳檔：`./expense-log.md`
- 審查報告：`./review.md`
- 行前清單：`./checklist.md`

## 協作設定
- 語言：繁體中文
- 行程輸出格式：單一檔案（推薦）/ 分日拆檔
```

同時將人的基本屬性儲存或更新至根目錄 `./traveler-profile.md`。

---

### 步驟 5：完成告知與下一步

完成後向使用者總結本次設定，並告知下一步：
> ✅ 已建立行程資料夾 `{$TRIP}` 與基本條件設定！
> 隨時說「下一步」即可啟動 `trip-research` 進行深度的景點、美食與簽證交通研究。
