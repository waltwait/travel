# 初始化與修改旅行

遵循 repo 根目錄 `AGENTS.md`。先判斷本次是新建、續填還是修改，保留既有資料。

## 收集與決策

- 先讀既有 `traveler-profile.md` 與選定行程的 `trip-meta.md`。已提供的航班、日期、住宿、偏好直接沿用。
- 優先補目的地、出發地、日期／天數、同行者；預算需區分每人／全團與是否含機票。未知可標待定，不能代填已訂。
- 只問影響本次決策的缺項，每次少量提問；使用者讓你決定時提出有依據的建議並揭露假設。
- 目的地未定時，按日期、交通可達性、預算、興趣比較少量候選並查當前資訊；確定地點再建立行程資料夾。
- 持用護照只在入境查核需要時問；完整姓名、聯絡人、證件號碼不是初始化必要條件。

## 儲存

1. 新行程使用 `{最大編號+1}-{地點}-{今日 YYYY-MM-DD}`，日期取系統當地日期。地點顯示名稱可保留原文，資料夾名稱移除路徑分隔符與控制字元，且不可覆蓋既有目錄。
2. 建立 `trip-meta.md` 後更新 `current-trip`；未收集完的欄位標待定，讓中斷後可接續。`research/` 等子目錄有內容要寫時再建立。
3. 修改或續填時局部更新，不用空白範本覆蓋整份 metadata 或 profile。放棄某趟就標 `aborted` 並保留檔案；新建另一趟用新編號。
4. `traveler-profile.md` 只保存跨旅行偏好；本趟旅伴、兒童年齡、預算、興趣、排除項、住宿和輸出格式寫本趟 metadata。

新 metadata 使用下列欄位，既有文件不必遷移格式：

```markdown
# {目的地} 旅行規劃
> 開始研究日期：{今日}

## 狀態
active

## 行程概要
- 目的地：
- 出發地：
- 日期與天數：
- 人數與旅伴：
- 預算與涵蓋項目：
- 航班／住宿及預訂狀態：

## 本趟行程設定
- 核心興趣與必去項：
- 排除項、飲食與體力需求：

## 關鍵檔案
- 旅行者畫像：../traveler-profile.md
- 研究報告：research/
- 行程：{存在的 Markdown 或網站路徑；否則待建立}

## 協作設定
- 語言：繁體中文
- 行程輸出格式：單一檔案
```

結尾說明已保存的條件、尚待決定事項與下一步；如原要求含完整規劃，繼續讀 [trip-research](../trip-research/SKILL.md)。
