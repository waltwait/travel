# 行前準備與打包清單 (trip-pack)

本技能依據出發剩餘天數、旅行天數、當地氣候與旅行者畫像，動態生成分階段行前待辦、行李打包檢核表與紙本緊急聯絡卡。

---

## 核心原則與個資防護

1. **動態時程倒數**：
   * 根據「出發剩餘天數」動態生成適合當下的檢查階段，不做無意義的過期提醒。
2. **個資安全原則**：
   * 緊急卡涉及個人姓名、護照號碼、緊急聯絡人與醫療備註，**僅留存於本機檔案**（`./$TRIP/emergency-card.md`）。
   * 絕不將敏感個資複製至公開網站（如 GitHub Pages `docs/`）或未經使用者同意之公開儲存庫。
3. **實體紙本備案**：
   * 重要證件翻拍、急難救助電話、保險單號與住宿地址，除手機備份外，強烈建議列印紙本隨身攜帶。

---

## 依剩餘天數之分階段時程

| 距出發天數 | 生成階段重點 |
| :--- | :--- |
| **> 90 天** | 3 個月前（護照/簽證/機票）、2 個月前（住宿/保險/熱門預約）、1 個月前（網卡/換匯）、2 週前、1 週前、前一天、當天、抵達。 |
| **30 ~ 90 天** | 即刻補齊項、1 個月前、2 週前、1 週前、前一天、當天、抵達。 |
| **14 ~ 30 天** | 立刻急件辦理項、2 週前、1 週前、前一天、當天、抵達。 |
| **7 ~ 14 天** | 衝刺版：明確標註「⚠️ 正常管道已來不及的項目」、1 週前最後準備、前一天、當天、抵達。 |
| **< 7 天** | 緊急衝刺：僅列出目前還能挽救的核心必要手續（電子入境申報、eSIM、離線地圖、現成藥品）與打包。 |

---

## 清單核心內容分類

### 一、 證件與金融手續
- [ ] 護照正本（確認效期大於目的地要求）
- [ ] 簽證 / 電子入境授權（如 ESTA / eTA / Visit Japan Web 申報）
- [ ] 信用卡（確認開啟海外實體刷卡與線上交易、提高臨時額度）
- [ ] 當地現金（依國家習慣準備適量紙鈔與硬幣零錢）
- [ ] 國際駕照與本國駕照正本（若有自駕租車）

### 二、 網路、通訊與電子器材
- [ ] 國外行動網路（eSIM 啟用代碼 / 實體 SIM 卡 / 漫遊開通）
- [ ] 行動電源（需隨身攜帶上機，不可託運；注意 Wh 限制）
- [ ] 萬國轉接頭與充電線（**若目的地電壓不同，檢查電器是否支援 100-240V 全球電壓**）
- [ ] 下載離線地圖（Google Maps / Naver Map）與離線語言翻譯包

### 三、 醫療與常備用藥
- [ ] 個人慢性病處方藥（含英文藥名證明）
- [ ] 旅遊常備成藥（腸胃藥、止痛退燒、綜合感冒藥、暈車/機藥、過敏藥、OK 繃）

### 四、 衣物與生活用品
- [ ] 依照出發月份當地氣候準備多層次穿著（洋蔥式穿法）
- [ ] 舒適好走之步行鞋（避免新鞋磨腳）
- [ ] 摺疊傘 / 輕便雨衣
- [ ] 保濕乳液、護唇膏（歐美日韓乾燥氣候特別需要）

## 紙本緊急卡（`emergency-card.md`）

於 `./$TRIP/emergency-card.md` 生成便於 A4 列印或截圖的手機緊急救護卡：

```markdown
# 旅行緊急聯絡卡 (Emergency Card)

> 建議列印 2 份（一份放隨身皮夾、一份放行李箱），並於手機相簿建立最愛備份。

## 1. 旅人與緊急聯絡人
* 持卡人姓名：{中文名} / {護照英文拼音}
* 血型 / 特殊過敏 / 疾病：{填寫或留空}
* 緊急聯絡人：{姓名}（關係：{關係}）
* 緊急聯絡電話：+{國碼} {電話號碼}

## 2. 當地緊急救難電話
* 報警 (Police)：{當地號碼}
* 救護車/消防 (Ambulance/Fire)：{當地號碼}
* 外交部/領事局駐當地館處：{代表處/大使館名稱}
  * 館處電話：{當地號碼}
  * 24 小時急難救助專線：{急難電話}

## 3. 海外急難與保險
* 保險公司名稱：{保險公司}
* 保單號碼：{保單號}
* 海外 24 小時急難救援服務電話：+{國碼} {電話號碼}

## 4. 住宿飯店聯絡資訊
* 飯店名稱：{飯店英文/當地語言名稱}
* 飯店地址：{完整當地地址}
* 飯店電話：{電話}

## 5. 信用卡緊急掛失專線
* Visa / MasterCard 海外免付費電話
* 發卡銀行 24 小時客服電話
```

## 交付與總結

1. 將完整行前檢核表寫入 `./$TRIP/checklist.md`。
2. 將紙本緊急聯絡卡寫入 `./$TRIP/emergency-card.md`。
3. 提示使用者：
   > ✅ 行前待辦清單與緊急聯絡卡已產出！
   > 出發前 1-2 天可再次檢核打勾；旅途中若需記帳或查詢替代景點，可隨時喚起對話。
