# 行前準備與打包

遵循 repo 根目錄 `AGENTS.md`。讀本趟 metadata、偏好、Markdown 或網站行程、既有 checklist 與審查待辦。不要求先完成全部研究或審查才能列清單。

## 清單

1. 由系統當地日期和出發日期計算剩餘時間；日期未知先提供不依日期的部分，需要截止日才補問。旅行已開始就列剩餘旅程需求，已結束則確認是否是整理／下次模板需求，不套出發前倒數。
2. 分成現在處理、出發前一週、前一天、當天與抵達；依剩餘時間合併，不列已過去的截止日作未來待辦。
3. 包含適用的證件／入境、交通與住宿、保險確認、網路／支付、行李限制、藥品、電器、天氣／活動裝備及兒童／行動需求。
4. 護照效期、辦理天數、入境登錄、駕照承認、保險義務、行動電源與用藥攜帶規則均查目的地／承運人官方來源。名稱出現在舊模板，不代表此旅程必須申請。
5. 即使距出發很近，仍保留未解決的必要證件／入境項，指出可行處理或實際限制；不能因「可能來不及」而刪掉。
6. 逐日穿衣建議只依涵蓋旅行日期的預報；長期規劃用季節參考並列出發前更新天氣待辦。
7. 更新 `{TRIP}/checklist.md`，保留使用者勾選與註記。新增項使用未勾選框；已完成項如果條件改變，說明為何需要重查。

## 緊急卡

- 使用者要求或近期出發確有需要時提供緊急卡。先產無個資範本，含已查證的當地緊急電話、適用館處來源、聯絡人／保險／住宿欄位。
- 個資不是完成一般打包清單的前提；不強迫收集姓名、血型、病史或護照號碼。不可承諾輸入助手或 repo 的資料絕不上傳伺服器。
- 使用者要填個資版時，依 `AGENTS.md` 選私人保存位置。確認 Git 未追蹤且忽略後才寫；沒有合適位置先保留空白，不把敏感資料寫進公開 `docs/`。
- HTML／列印版只在需要時製作，內容與來源保持一致。

回覆最急的未完成項、可稍後做的項目與清單位置。說明清單已產出，不等同使用者已辦妥；不執行未授權的購票、申請或付款。
