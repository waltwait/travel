# 目的地深度研究 (trip-research)

本技能針對目的地的入境條件、交通動線、熱門景點、在地美食、住宿與安全進行多維度事實查證與深度調研。

---

## 核心研究原則

1. **查證真實時效**：
   * 票價、營運時間、交通班次、簽證規則等動態資訊，必須透過 `search_web` 或相關工具檢索最新資料。
   * 所有重要事實需標註來源 URL、查詢日期與適用日期；不可捏造不存在的票價或班次。
2. **依真實條件查證**：
   * 簽證與出入境規定須依使用者**實際持用護照國籍**為準，不得預設特定國籍。
   * 護照效期依照目的地國官方規定，不直接套用通用「六個月」規則。
   * 時差與轉機時間（MCT）依實際起飛地、轉機機場與航班航廈流程查詢。
3. **結構化持久儲存**：
   * 所有研究結果皆寫入 `./$TRIP/research/` 目錄，確保中斷後可無縫續跑。

---

## 執行流程

### 步驟 1：前置門檻把關（Gate Check：簽證與時效）

在展開景點調查前，必須先確保法律與入境條件可行：
1. **確認基本證件**：
   * 從 `traveler-profile.md` 讀取使用者「國籍」與「護照效期現況」（若無則先詢問）。
2. **查核目的地與轉機國規定**：
   * 目的地對持該國籍護照之簽證政策（免簽、落地簽、e-Visa、紙本面簽）。
   * 若含轉機，是否有過境簽證或電子旅行許可（如 ESTA、eTA、過境免簽口岸）之限制。
   * 辦理簽證/更換護照所需工作天數。
3. **紅黃綠燈判斷**：
   * 🟢 **充裕綠燈**：距出發天數 > 辦理所需天數 × 2，證件完全無虞。
   * 🟡 **緊急黃燈**：距出發天數 > 辦理所需天數，但時間緊湊，需在報告開頭提醒使用者立即送件。
   * 🔴 **來不及紅燈**：距出發天數 < 辦理所需天數。此時應暫停並提供選項：改期、改目的地、辦理急件或放棄規劃。
4. **輸出 Gate 報告**：存為 `./$TRIP/research/agent-0-gate.md`。

### 步驟 2：生成研究項目清單（`research-checklist.md`）

根據旅行者畫像（核心興趣、旅伴、預算），於 `./$TRIP/research/research-checklist.md` 動態生成具體檢查清單：

```markdown
# 研究項目清單 — {目的地}

## A. 核心體驗與景點
- [ ] A1: 標誌性核心景點與預約規則
- [ ] A2: 攝影熱點 / 推薦拍攝時段（Golden Hour）
- [ ] A3: 文化歷史體驗或特色街區
- [ ] A4: 備用景點（雨天或空檔備案）

## B. 在地飲食與餐飲預算
- [ ] B1: 每日飲食花費估算（早/午/晚）
- [ ] B2: 在地必吃特色料理清單（附店家地址與地圖連結）
- [ ] B3: 特殊飲食需求替代方案（素食/過敏/清真）
- [ ] B4: 當地自來水飲用標準與買水須知

## C. 交通與票券
- [ ] C1: 機場往返市區最優交通方案
- [ ] C2: 市內大眾運輸（地鐵/公車/計程車叫車 App）
- [ ] C3: 交通票券/觀光 Pass 划算度評估
- [ ] C4: 城際交通方案（鐵路班次、預先訂票管道）

## D. 住宿選擇
- [ ] D1: 推薦 3-4 間符合預算與等級的住宿評比（含優缺點與價格）
- [ ] D2: 住宿區域安全與生活機能分析
- [ ] D3: 兒童/家庭設施確認（若同行者有小孩）

## E. 安全與生活實用
- [ ] E1: 治安現況、常見詐騙手段與危險區域
- [ ] E2: 當地急難電話（警察、救護車、駐外館處聯繫方式）
- [ ] E3: 電壓、插座規格與變壓器/轉接頭需求
- [ ] E4: 支付方式（現金準備比例、信用卡接受度、退稅規則）
- [ ] E5: 小費文化與公共廁所收費習慣

## F. 當季與特殊狀況
- [ ] F1: 旅遊期間當地氣候、預報或歷史溫度與穿著建議
- [ ] F2: 當季節慶、特殊市集或限定活動
- [ ] F3: 國定假日對商店/景點公休之影響
- [ ] F4: 罷工、施工或夏令時間調整注意
```

### 步驟 3：執行多維度調研

可依研究範圍選擇直接研究或派發研究 subagent（`invoke_subagent`）：
1. **資訊檢索**：
   * 活用 `search_web` 搜尋目的地最新交通票價、景點門票預約規定、公休日與美食評價。
   * 韓國景點與店家優先查證韓文名稱與 Naver Map 正確分店；其他地區使用 Google Maps 街道與英文/當地語言搜尋。
2. **多方來源交叉驗證**：
   * 關鍵事實（如休館日、高額門票）從官方網站與旅遊社群（真實旅人反饋）雙重查證，避免過期資訊。
   * 遇到資訊衝突時，標註「⚠️ 資訊分歧」，說明兩方差異。
3. **報告分篇寫入**：
   * `./$TRIP/research/attractions.md`（景點與核心體驗）
   * `./$TRIP/research/food.md`（美食與餐飲花費）
   * `./$TRIP/research/transit.md`（交通動線與票券）
   * `./$TRIP/research/lodging.md`（住宿評估）
   * `./$TRIP/research/practical.md`（安全、電壓、換匯與當季須知）

---

### 步驟 4：總結與下一步引導

完成所有調研項目後：
1. 更新 `research-checklist.md` 的勾選狀態。
2. 產出研究總覽摘要，向使用者回報：
   * 簽證與證件狀況
   * 推薦的核心亮點與排程建議
   * 重要警示（如某景點需提早一個月預約、某日為公休日）
3. 引導使用者進入下一步：
   > ✅ 深度研究已全數完成並存入 `./$TRIP/research/`！
   > 隨時說「下一步」即可啟動 `trip-go` 編排每日具體動線與交通時刻表。
